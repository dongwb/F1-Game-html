# F1 赛车游戏 Grand Prix

一个纯前端的 F1 赛车游戏：单文件 `index.html`，零依赖，浏览器打开即玩。

支持单人/双人同屏对战、AI 对手、6 级难度、15 条真实 F1 赛道、DRS 减阻系统、尾流滑流等真实赛车要素。

## 快速开始

```bash
# 直接用浏览器打开即可，无需构建、无需服务器
open index.html
```

## 玩法特性

- **15 条真实 F1 赛道** — 巴林、上赛、摩纳哥、蒙扎、银石、斯帕替代站赞德沃特等，基于 [meijersa/f1-circuits](https://github.com/meijersa/f1-circuits) GeoJSON 数据集生成（GPS → 平滑 → 重采样 → Catmull-Rom 样条）
- **单人 / 双人同屏** — 双人模式分屏双相机，各看各的视角
- **AI 对手** — Pure Pursuit 路径跟踪 + 曲率速度剖面，最多 2 台 AI 同场
- **6 级难度梯度** — 简单 / 中等 / 困难 / 超级困难 / 地狱级 / 首领（AI 极速 0.90×~1.40×，过弯 80%~100%）
- **DRS 减阻系统** — 直道可激活，+45 极速持续 3 秒；正常冷却 10 秒，完成干净圈（无冲出无碰撞）冷却减半
- **尾流 / 滑流** — 跟随前车获得极速加成，尾流沿真实轨迹弯曲成圆弧，符合空气动力学
- **完整比赛流程** — 发车格起步、圈数统计（3/5/8 圈可选）、排名 HUD、圈速计时

## 技术要点

- **技术栈**：HTML5 Canvas + 原生 JavaScript，无任何外部依赖
- **赛车物理**：速度/档位模拟、空气阻力、出赛道额外阻力、速度自适应转向灵敏度
- **AI 驾驶**：Pure Pursuit 跟踪预计算速度剖面（按曲率求弯心极限速度，前后双向平滑）
- **渲染**：俯视卡通 F1 车体（宽前翼、鼻锥、侧箱收腰、刹车红光）、动态尾流条带、DRS 尾焰
- **圈数检测**：基于赛道点绕圈进度，冲出赛道重设不污染圈数统计
